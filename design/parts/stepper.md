# Stepper

`SbStepper` · Android only

A small number that is set with minus and plus, such as a number of repetitions.

## States

- At the smallest value minus is disabled, at the largest plus.

## Behaviour

- The label stands above; below it minus, the value and plus in one row.
- The value is in tabular figures, centred in the width of the widest value, so the buttons never move.
- Minus and plus are icon buttons named „<Label> weniger“ and „<Label> mehr“.
- Each change is announced politely with its word („13 Wiederholungen“).
- Holding a button does not count on.

## Rules

- A small number is a stepper, never a number field. There is no field to type in. [EIN-06]
