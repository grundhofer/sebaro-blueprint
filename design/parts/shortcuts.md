# Fixed shortcuts

No class of its own · web and desktop

Fifteen shortcuts are the same in every desktop app and web app with a window.

| Action | macOS | Windows and Linux |
|---|---|---|
| Befehlspalette | ⌘K | Strg+K |
| Einstellungen | ⌘, | Strg+, |
| Hauptaktion des Bereichs | ⌘N | Strg+N |
| Öffnen | ⌘O | Strg+O |
| Suchen in der Ansicht | ⌘F | Strg+F |
| Seitenleiste ein und aus | ⌃⌘S | Strg+Alt+S |
| Inspektor ein und aus | ⌥⌘I | Strg+Alt+I |
| Nächster / vorheriger Bereich | F6 / ⇧F6 | F6 / Umschalt+F6 |
| Nächster / vorheriger Reiter | ⌃⇥ / ⌃⇧⇥ | Strg+Tab / Strg+Umschalt+Tab |
| Reiter oder Fenster schließen | ⌘W | Strg+W |
| Neues Fenster | ⇧⌘N | Strg+Umschalt+N |
| Widerrufen / Wiederholen | ⌘Z / ⇧⌘Z | Strg+Z / Strg+Y |
| Löschen … | ⌘⌫ | Entf |
| Schrift größer / kleiner | ⌘+ / ⌘− | Strg++ / Strg+- |
| Zurück / Vor | ⌘← / ⌘→, in a text field ⌃⌘← / ⌃⌘→ | Alt+← / Alt+→ |

## Behaviour

- The window's shortcuts rest while a dialog, a menu or the palette has the keyboard.
- The table means characters, not physical keys: ⌘+ is the character „+“ wherever the layout puts it.
- A text field keeps its keys: deleting, line start and end, undo and redo, cut, copy, paste and select all.
- „Schrift größer“ and „Schrift kleiner“ change only the content: the editor's text size or the reader's zoom. The
  window's parts keep their size.
- In a browser some chords belong to the browser; there the menu and the palette are the way.

## Rules

- No app uses one of them for anything else. An app's own shortcuts stand in its palette and its menu. [DSK-09]
- No shortcut needs a key that the German keyboard makes only with ⌥ or AltGr (`\ [ ] { } @ | ~`). On Windows, never
  Strg+Alt with a key that gives a character under AltGr. [DSK-09]
- Never a chord the system keeps, such as ⌘Q, ⌘H, Alt+F4 or any chord with the Windows key.
- „Löschen …“ always opens the dialog; with a trash it reads „In den Papierkorb legen …“. [K15]
