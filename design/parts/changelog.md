# Changelog

`sb-changelog` · web only

What changed and when: rows of a date and a text.

## Behaviour

- Each row has the date in tabular figures and `text-muted`, then the text. Hairlines stand between the rows.
- In a narrow place the date stands on a line of its own above its text.

## Rules

- Dates use tabular figures, never mono. [K8]
