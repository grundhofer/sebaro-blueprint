# Tag and demo marker

`sb-tag`, `sb-tags`, `sb-demo-marker` · `SbTag`, `SbTags`, `SbDemoMarker`

A tag is an outlined word that states a fact about a thing: „Android“, „Verfügbar“, „Beta“. The demo marker is the
same shape with the word „Beispieldaten“.

## Rules

- Never clickable, never in a status colour. „Beta“ is a tag, not a status. [STA-04]
- A clickable #keyword is a link in the link style, with the # as part of its words. [STA-04]
- A tag is a fact, not an emphasis: it has the regular weight.
- Sample data carries the marker „Beispieldaten“. [K27]
- Never a pill. [FOR-06]
